# Dakhlek website — ready for GitHub Pages

This package contains the complete static website for Dakhlek (دخلك), including:
- Arabic / English language switcher
- About, Privacy and Support pages
- Official transparent Dakhlek logo
- Real app screenshots: Dashboard, Smart Financial Health, Reports Summary, Reports Categories, Gold Prices, Currency Exchange
- Responsive layout for desktop and mobile

## Upload
Upload the contents of this folder to the root of your GitHub Pages repository (or any static web host). `index.html` must remain at the root.

## Before public launch
Replace any placeholder/store-launch wording when the Google Play production link is available. The current screenshots are from the test build and can be refreshed after translation cleanup.
